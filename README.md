## 📋 Overview

**TechCall** is a mobile application built to support **field service technicians** in their day-to-day work. It centralizes the service calls a technician has to attend, so they can see what's assigned to them, keep each job up to date, and register what was done on site — all from their phone.

The goal is to replace scattered notes and phone calls with a single, simple tool made for who is actually out in the field.

---

## ✨ Features

- 📅 View and manage assigned service calls / work orders
- 📝 Register on-site visits with notes and status updates
- 🔄 Track each call's status (open, in progress, resolved)
- 📸 Attach photos taken during the visit to a call
- 🗂️ Browse call history

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- The [Expo Go](https://expo.dev/go) app on your phone, or an Android/iOS emulator

### Installation

```bash
# Clone the repository
git clone https://github.com/vitordev18/techcall.git
cd techcall

# Install dependencies
npm install

# Start the development server
npx expo start
```

Then scan the QR code with **Expo Go**, or press `a` / `i` to open an Android / iOS emulator.
